# Test-Checkliste fürs Handy

Bitte der Reihe nach ausprobieren und notieren, was nicht klappt (mit Nummer). Dann verbessere ich es.

## A. Start & Bibliothek
1. App startet im Querformat, dunkler Bildschirm, oben „HIRSCH EXPRESS DJ“.
2. Frage nach „Musik und Audio“ → Erlauben → Meldung „… Titel gefunden“.
3. ♫ Bibliothek: Liste mit Titel, Interpret, Länge. BPM erscheinen nach und nach („…“ = wird noch berechnet).
4. Suche: ein paar Buchstaben eines Interpreten eintippen → Liste wird gefiltert.

## B. Decks
5. Titel mit **A** laden → Titel, Wellenform und BPM erscheinen links.
6. ▶ drückt → Musik läuft, weisse Linie wandert. ❚❚ = Pause.
7. Auf die untere (kleine) Wellenform tippen → springt an diese Stelle.
8. CUE: im Pausenzustand an eine Stelle → CUE drücken (gelbe Linie) → ▶ → CUE → springt zurück und hält an.
9. Zweiten Titel mit **B** laden.

## C. Mixer
10. Lautstärke-Regler A/B (Mitte) hoch/runter ziehen.
11. Crossfader ganz links → nur A, ganz rechts → nur B. Doppeltippen → Mitte.
12. MASTER-Knopf verändert die Gesamtlautstärke. Pegelanzeigen bewegen sich.

## D. Tempo & Sync
13. Tempo-Regler ziehen → BPM-Zahl ändert sich, Tonhöhe bleibt gleich (KEY leuchtet).
14. KEY ausschalten → schneller = höher (wie Plattenspieler).
15. ±8% antippen → wird ±16%.
16. A spielt, B spielt → bei B **SYNC** → gleiche BPM, Beats laufen gleich (Raster in der Zoom-Wellenform übereinander).
17. ‹ › gedrückt halten → kurz langsamer/schneller.

## E. EQ & Effekte
18. HOCH / MITTE / TIEF drehen (hoch/runter ziehen). KILL → Band weg.
19. FILTER nach links → dumpf, nach rechts → dünn.
20. ECHO einschalten → Echo im Takt, Knopf = Stärke.

## F. Kopfhörer (falls Kabel/Adapter vorhanden)
21. ⚙ → Ausgabe-Modus wählen (Splitter / USB / zwei Geräte).
22. 🎧 bei einem Deck → im Kopfhörer hörbar.

## G. Aufnahme
23. ● Aufnahme → Zeit läuft → nochmals drücken → Meldung „gespeichert“.
24. In „Eigene Dateien“ → Musik → HirschExpressDJ → WAV-Datei abspielbar.

## H. Gästewünsche (nach FIREBASE_ANLEITUNG.md)
25. ★ Wünsche → Event starten → QR-Code erscheint.
26. Mit einem anderen Handy scannen → Song suchen → senden → erscheint nach ein paar Sekunden in der App.
27. Zweiter Wunsch sofort danach → Meldung „nur alle 5 Minuten“.
28. ✓ und 🗑 ausprobieren.

## I. Robustheit
29. Home-Taste → Musik läuft weiter → App wieder öffnen → alles noch da.
30. Bluetooth-Box verbinden/trennen während Musik läuft → Ton wechselt das Gerät.
